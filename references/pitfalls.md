# Pitfalls

Every entry here was really hit. Check here first when something odd happens; append new pitfalls to the matching category.

## Content and creativity

| Pitfall | Symptom | Fix |
|---|---|---|
| Pacing too fast | The user reported "the audience can't keep up": 0.45-second fast cuts, 3.6-second information scenes | Follow the pacing floors in AGENTS.md; when slowing down, slow the information-dense sections first, and leave visually impactful sections as they are |
| The URL only appears at the end, and is hidden in the web version | The user said "nowhere in the whole film is the full URL shown" | Put a prominent URL once in the climax segment (address-bar style), once more at the end, and do not hide the URL in the web version's end screen |
| Passing off another product's work | The best-looking screenshot was the model vendor's official demo | Check the image's context to verify attribution; if unsure, do not use it |
| Only looking at the first few images of each document | The best result images were missed in the article's "feature demo" section | Download all images and build a contact sheet per document to pick through |
| The same work appears twice | Two similar screenshots were treated as two works | Keep only the single most representative image per work |
| Too little about the product itself | Endorsements and numbers took up too much, so the product's overall picture was unclear | Convey richness through a module overview, real pages, and section / feature lists; mention endorsements in passing |
| The style slides back to default | Every film turns out dark blue-purple tech style | The style must be confirmed through the requirements interview, with sample frames shown to the user |
| The product the user named is not released yet | "Make a promo video for the new Fable 5.5," but the official site only had 5.1 and 5.5 was just that day's limited-rollout rumor | Check the official news page as the first step of pre-research; with no official source, ask about positioning first (see step zero of `requirements-interview.md`), and do not write rumors into the film as facts |
| Riddle-style opening | "It's labeled Fable 5.1, but the answer isn't it?" Insiders found it clever, but the user said "it leaves people lost, the story isn't told clearly" | Explain the event in one plain sentence first, then what happened; add explanation cards for memes and names; run the outsider retelling test before delivery |
| Adding qualifiers to a case that the original post did not have | Wrote "drawn in pure SVG code," "a short film with a soundtrack," "seven art styles," none of which the original post said | Use only information present in the original post / official wording for captions; check item by item in the image review checklist |
| Second-hand coverage case with no findable original post | The jellyfish comparison, the pelican riding a bike, and the seven wonders only appeared in a 新智元 retelling | Delete cases whose original post cannot be found; for the same work reposted, credit only the original author; dates in second-hand coverage are often Beijing time, so defer to the official source |
| Treating a 404 on a doc URL as proof of a leak | The community said `.../models/fable-5-5/overview` returned 404 | Any nonexistent path returns 404 and proves nothing; do not put it in the film |
| Treating a pagination number as the total count | A firecrawl Q&A said "Skills lists 341," but 341 was the last page number (the real count was 8169) | Check the context of numbers on list pages first; count totals yourself as "(last page number - 1) × items per page + items on the last page," and verify by clicking through to `?current=<last page>` with Playwright |

## Visuals

| Pitfall | Symptom | Fix |
|---|---|---|
| Text in the same color family as its background | Blue-cyan gradient text on a light blue background, white text over a sunrise light effect | Darken the text color + add a white/black glow (`filter: drop-shadow`), or dim the background behind the text |
| A narrow card's horizontal title wraps | "五大核心心 / 法" | Vertical text (`writing-mode: vertical-rl` + `textOrientation: upright` + `whiteSpace: nowrap`), or widen the card or reduce the number of cards |
| Fan-stacked cards occlude each other | A later card covers the text of an earlier one | Reduce the overlap or keep the text area in the visible portion; look specifically for this in image review |
| Enlarging a small image | A 180×208 screenshot looks blurry in a 4K frame | `check_assets.py` flags it; replace the image |
| Ordinary fonts | The user said "not techy enough" | Switch titles to a font with character (chosen by style), keeping PingFang for body text |
| UI numbers overflowing | A stat card subtitle or legend wrapping and overflowing | Set a fixed width + `whiteSpace: nowrap`, and look specifically at small text during image review |
| Same-colored element behind same-colored text | A brand-blue slogan over a brand-blue small icon, making the text look gouged out | Look specifically at "moving element × text" overlaps during image review, and move one of them |
| A landmark blocking the route on an isometric map | A landmark tower covers a route corner, making the cursor look stuck to the building face | Put landmarks in blocks where "the front corner is the route corner," so the route and cursor are always in front of the buildings |
| An English title squeezed onto a second line | "Claude Fable 5.5" at 196px exceeded the dossier folder's width, and "5.5" dropped to the next line over the seal | Always use `whiteSpace: nowrap` for large titles, estimate width by the widest character (ShuHei Latin letters are about 0.6em), and confirm with a screenshot |
| Montage text unreadable over a bright picture | White text relying on a shadow blurs over bright shots like newspapers or stained glass | Add a dark backing strip to all text over video (`rgba(10,9,8,0.82)`), and darken the top gradient |
| Screenshot assets too low-resolution | A 200×200 course cover or a 646×300 project cover looks blurry enlarged to 4K | Redraw cards and icons in code (taking the text from the cover's original wording), and only place real images that are large enough (≥ display width × 2) directly in the frame |
| Hand-drawn strokes becoming a dashed line | On the Old Fish Resume: red underline and big red X drawn with `viewBox="0 0 100 100"` + `preserveAspectRatio="none"` + `vectorEffect="non-scaling-stroke"`, with `strokeDasharray` computed from the path length in the viewBox, the actual on-screen length was several times larger, so the stroke broke into segments | When animating "a stroke being drawn," convert the path coordinates to pixels first and measure the length with `getLength`; do not rely on viewBox stretching |
| All web screenshots squashed horizontally | Yupi AI Navigation: the browser window enlarged the screenshot by 1.12–1.3×, and the user said "the proportions are all off, it feels like everything is squashed." Tailwind's base styles add `max-width: 100%` to `img`, so the width was pushed back to the window width while the inline height stayed the same | The template's `src/index.css` now has `img, video { max-width: none; }`; place screenshots with the template's `BrowserFrame` (computing width and height from the source image's ratio); during image review check whether circular avatars in screenshots are still perfect circles |

## Audio

| Pitfall | Symptom | Fix |
|---|---|---|
| The opening music is "weird" | Starting mid-phrase + a synthesized low-frequency drone clashing with the track's tonality | Enter on a bar line, use `build_in` to build up, delete the drone, and use only sound effects before the drop |
| Sound effects misaligned after a pacing change | Seconds hard-coded in mix.py | Compute all time points from `timing.json` (including `pace`) |
| Cannot hear the sound | The AI cannot make a subjective judgment | Use `music.py bars` and `mix.py --env` to look at the curves; ask the user to listen in person at delivery |
| A stuttering track is not obvious | "Island Beat" had very even per-bar energy, and only after mixing did `--env` reveal that the second half of each bar was near-silent (-79 dB), making continuous visuals stutter | When choosing a track, also measure the fraction of the main section below -30 dB in 0.1-second windows (> 3% is a warning sign); for continuous tracks, shape the structure with filters: high-pass fade-in for the intro, low-pass "muffling" for the quiet passage, full band at the drop |
| High-energy EDM under a pain-point opening sounds "weird" | Codefather version 2: the picture was describing pain points while the music was club-like from the first beat | The music mood follows the narrative: puzzled / tense at the start (sparse, no drums, unresolved), entering the high-energy section only at the brand drop; with a paid ElevenLabs account, compose from the storyboard |
| ElevenLabs composition section durations are inaccurate | The planned intro was 4.36 seconds but actually 7.6 seconds; the breakdown was 3 seconds late | The v2 series ignores duration. Measure the real structure with `grid` + `bars`, use `musicOffset` to skip the excess intro, move scene boundaries onto the real drop and breakdown, and stitch on bar lines when it is too short |
| ElevenLabs free plan | The composition endpoint returns 402; sound effects work but cannot be used commercially | Check the plan with `elevenlabs.py quota` first; after upgrading, regenerate the assets created during the free period with the same prompts |
| A one-shot sound effect cannot fill a scene | Three "puzzled intro" effects all decayed to -60 dB within 2 seconds | Use `--loop` + `continuous, no silence` when a bed is needed; measure the envelope after generating each effect |
| The riser's peak is at the start | Both generated risers peaked at around 0.3 seconds | Write `grows steadily and ends exactly at its peak` in the prompt and confirm the peak position after generating |
| Concurrent requests return 429 | The free plan sent 5 requests at once and the first was rejected | Generate one at a time (`elevenlabs.py` retries automatically) |
| A professional cloned voice is unusable | `voice_not_fine_tuned`: the author's own professional cloned voice is still training | Use a voice-library voice first; once training finishes, change `voice.voiceId` back to it and run `vo` + `mix` + swap the audio track, with no re-render needed |
| v4 cannot adjust the speaking rate | `speed` and `style` have no effect on v4, and the same line's duration fluctuates by ±10% between generations | Write the script within a character budget; the script auto-speeds up by at most 12%; merge lines with a time window < 2.2 seconds into an adjacent line |
| Narration buried by the music | With the voice at -18 dB and the music ducked 7 dB, the voice was only 1–2 dB above the music in high-energy sections | Defaults are `rmsDb -13` and `duckDb -9`; check that `vo_margin` is ≥ +8 dB for every line |
| A cloned voice articulates unsteadily | The author's own cloned voice had no v4 training, and after switching to multilingual_v2 at stability 0.5 several lines transcribed wrong | Raise stability to 0.85; use `vo --takes 4` to generate several takes per line and keep the most accurate; reword words that cannot be pronounced clearly |
| Brand name mispronounced yet all checks pass | Yupi AI Navigation: multilingual_v2 ran "鱼皮 AI" together into "pai," heard as "鱼排"; the URL line transcribed as "语牌 AI 导航…" with a whole-sentence similarity of 0.90, passing the 0.85 threshold | List brand names and URLs in `voice.keywords` so one missing occurrence is judged `CHECK_WORD`; commas, quotes, and splitting letters cannot save multilingual_v2—switch to `eleven_v3` + `sts` |
| Pronunciation fixed but the timbre changed | After switching to eleven_v3 the pronunciation was all correct, but the user said "the voice doesn't sound like mine anymore": this cloned voice was only trained on the v2 series, so v3 used an approximate timbre | `voice.sts: true`: after v3 reads accurately, convert back to the person's own timbre with the trained `eleven_multilingual_sts_v2`; produce 3 sample lines before changing the model |
| Timbre conversion blurs a short word | "试试鱼皮 AI 导航！" transcribed correctly from v3's original audio, but after converting to the person's own timbre, all 4 takes became "设置 / 这是 / 就是鱼皮 AI 导航" | `vo`'s multi-take selection now happens after timbre conversion; add a leading word and a comma before the brand name: "快来试试，鱼皮 AI 导航！" passed on the first try |
| The character has an echo | On multilingual_v2 the cloned voice had a 90–360 ms reverb tail at each sentence end, sounding like an echo under the music; trying to remove it with Audio Isolation failed with 400 because a single line is under 4.6 seconds | `vo` measures `tail_ms` automatically and judges `ECHO` above 250 ms; after switching to v3 + `sts` it dropped to 20–110 ms |
| A children's song under a chibi art style | Yupi AI Navigation version 1 picked the childlike "Kids," version 2 switched to upbeat pop, and both were rejected | Music follows the audience and the product (university students and professionals learning AI → bright and inspiring, with dynamics); after two rejections, widen the styles and produce 5–6 samples layered with the narration for the user to choose from |
| Treating transcription error as a mixing problem | Mianshiya's "再精挑" was heard as "带金条," and at the time it was thought the riser was covering the voice, so the sound effect was deleted and this was even written into the docs; a later comparison (transcribing the same stretch 3 times with and without the riser) was all correct, and what actually fixed it was simultaneously swapping in a clearer take | `check-mix` now automatically re-checks cut segments twice; when a line is genuinely unclear, regenerate that line first; when suspecting a sound effect or the mix, do before/after control transcriptions first, and only change things and write them into the docs once you have evidence |
| `check-mix` false positives | Scribe inserted "[动感的背景音乐]" into the transcript; one wrong homophone mid-sentence made the whole line count as unheard | Fixed: strip bracketed tags before comparison and switch to a sliding-window similarity ≥ 0.8 per line |
| The project scripts are old during revision | After Mianshiya copied the template, the template gained voice-over-music ducking, `check-mix`, and the web audio clock; the project had none of them, and `mix.py` was still on the previous storyboard | Always run `python3 scripts/sync_template.py` first when revising or continuing an old project; after reordering scenes, rewrite `mix.py` for the new storyboard |
| Build artifacts ended up inside the template | Running `mix.py` experimentally in the template left `public/audio/mix.wav` and `audio-src/_mix_raw.wav` in the template, which would be copied into every new project | Do not run generating commands in the template; to try something, `cp -R template /tmp/x` and run in the copy |
| Clear on its own, unclear once mixed | The URL transcribed as "codefather.cn" on its own but became "点 CM" in the finished mix | `check-mix` transcribes the finished mix; give the key line its own `duckDb: -14`, soften the high-frequency sound effect at the same moment, and write the `say` with capital letters "C N" |
| A cloned voice has odd tones | After scoring the whole film with the author's own cloned voice, the user said "a lot of the tones are a bit off"; the transcription also failed frequently ("路由→绿油," "五点五→无电雾," "十月→日月") | Audition the cloned voice alongside 2 voice-library voices and let the user choose; the Fable film switched to Haoran (v4) and the mix transcribed at 1.000 |
| Mishearing that changes a fact | "Fable 5.5 一上线" was transcribed as "已上线"; "五点五一正式发布" as "5.51" | These are not homophone problems and the script must change: "等它正式发布"; do not follow a number with "一 / 已" |
| The composition did not deliver the planned quiet section | The plan had an interlude (clock ticking only), but both generated versions were full-energy | `audiolib.muffle` low-passes those bars, then restores full band at the end into the hard hit |
| A self-written silence trim muted the whole line | `afade=t=out:st=0` made the fade-out start at second 0; the duration looked normal but the transcript was "blank audio" | Fixed; always transcribe after generating, since a normal duration does not mean there is sound |

## Engineering and rendering

| Pitfall | Symptom | Fix |
|---|---|---|
| 4K render image decode failure | The log had 32 `EncodingError: The source image cannot be decoded`, yet the render reported success | When many large images share a screen, prepare a downscaled version for that scene (display width × 2 is enough) and lower `--concurrency` to 6 |
| Floating-point error in duration × frame rate | `78.4 * 60 = 4704.000000000001` | `Math.round(timing.duration * fps)` (already handled in the template) |
| `npm install` reports ERESOLVE (@types/react-dom 19.3 requires @types/react ^19.3) | The template lock was missing `@types/react-dom`, and `^19.2.0` pulled a newer version | The template now pins `"@types/react-dom": "19.2.3"` and has an updated lock; always pin versions when adding dependencies in the future |
| `legacy-peer-deps` breaks dependencies | Bundling fails with `Cannot find module 'ajv/dist/compile/codegen'` | Do not use legacy-peer-deps; the template pins compatible versions (vite 6 + @vitejs/plugin-react 4), so use the template's own package-lock |
| `prefetch is not a function` | Imported from `@remotion/preload` | Import `prefetch` from `remotion` |
| The web version's narration is "two people talking, echoing throughout" | `@remotion/media`'s `<Audio>` plays in Web Audio chunks, and when the browser cannot keep up with the frame rate it resynchronizes repeatedly, scheduling new chunks while old ones are still playing: 1948 chunks of 43 ms were started in 4 seconds (normally about 94), overlapping about 6 copies at any moment | Keep the Player out of audio in the web version (`withAudio: false`) and use a plain `<audio>` as the clock, seeking the Player to the matching frame each frame, dropping frames when the picture cannot keep up (already handled in the template's `web/App.tsx`). An intermediate attempt replaced the Player's audio with `<Html5Audio>`: the stacking stopped, but the Player pulled the sound back 0.7 seconds every 2 seconds to wait for the picture, replaying the last half-sentence and still sounding like "a double echo." Verification: play for 10 seconds in real Chrome; `<audio>.currentTime` rises by 1.0 per second and never goes backward, and the `AudioBufferSourceNode.start` count is 0. Close the test page when done, or its sound will overlap what the user is listening to |
| The web version has "no sound at all" | Yupi AI Navigation: pressing play in Cursor's built-in browser advanced the picture but not a single audio sample was sent within 3 seconds; the same page played fine in Chromium. Also, a server started with `python3 -m http.server` does not support Range requests, so audio cannot be read on demand | `npm run web:build && npm run web:serve` (http-server, which supports Range), and open `http://127.0.0.1:18765` in the system browser; use the built-in browser only to look at the picture |
| The user logged in via the built-in browser, but screenshots are only 1× | The built-in browser's 2× pixel-density emulation tiles screenshots incorrectly, while a separately opened Chrome has no login state | Prefer asking the user to log in once more in the window that `shot.py --login` opens; when that is inconvenient, use `scripts/snapshot.js` to export a self-contained HTML from the logged-in page and `scripts/snapshot.py` to re-render it locally at 1920×1080 @2x (see `asset-sourcing.md`) |
| The mix was changed mid-render | A 4K render reads `public/audio/mix.wav` (also when muxing the audio track at the end), so remixing during a render may read a half-written file | During a render, write the new mix elsewhere (`Mix.master(dest="out/mix-vo.wav")`) and overwrite afterward, or swap the new audio track into the finished video with ffmpeg |
| `curl` silently failed to download all X images | `pbs.twimg.com` had its connection reset, `curl` does not read the macOS system proxy, and `check=False` swallowed the errors, leaving only `meta.json` | Use `xgrab.py` (reads the system proxy automatically and prints failures); when writing your own, check the port with `scutil --proxy` then use `-x` |
| ElevenLabs occasionally reports `Connection reset by peer` | Half of 8 consecutive sound-effect generations failed, and the retry loop used `tail` to judge success so it never retried | `elevenlabs.py` now retries network errors automatically; when writing your own retry, judge success by "the target file exists" |
| Variables are not split on spaces in zsh | `V="-an -vf …"; ffmpeg $V` fails with `Unrecognized option 'an -vf …'` | zsh does not word-split by default: write all arguments out, or use `${=V}` |
| `Sequence` has no `premountFor` | Remotion 4.0.529's `<Sequence>` type lacks this property, so tsc errors | Remove it; register assets in `src/assets.ts` when preloading is needed |
| `check_assets.py` reports "missing file public/)}.jpg" | An asset path was written as a template literal `` `tpl/m/${String(i).padStart(2, "0")}.jpg` ``, and the checking script matched by quotes, treating `)}.jpg` as a file name | Write grouped asset paths as literal arrays (exported from `src/assets.ts`) and index into them in scenes |
| `stills.mjs` clears `out/stills/` on every run | After capturing a batch of scene images and then adding a few more, the earlier files were gone | Pass all the time points you want to compare at once, or copy out the ones you want to keep first |
| Writing `\uXXXX` escapes in the question tool's parameters (Cursor's `AskQuestion`) | The questions were treated as placeholders and never shown to the user | Write plain text directly |
| Running dependent commands in parallel | Writing a file and `cp`-ing the same file were issued at the same time and `cp` could not find the file; mixing immediately after copying a track read incomplete data (a whole silent stretch appeared in the mix) | Chain steps with dependencies using `&&` rather than splitting them into parallel calls; after mixing, check the `--env` curve for abnormal silence |
| The web player jumps back to the first frame when playback ends | The Player's `moveToBeginningWhenEnded` default | Set it to `false` (already handled in the template) |
| A control appears in the bottom-right during playback | The volume button covers the picture | During playback keep only the 2px progress bar at the bottom (already handled in the template) |
| PingFang not found | Newer macOS does not have it under `/System/Library/Fonts` | `fonts.py` searches `/System/Library/AssetsV2/com_apple_MobileAsset_Font*/*/AssetData/` automatically |
| eslint reports background-image | The Remotion rule `no-background-image` | Use `<Img>` for background images; when you really need a CSS background, make sure the asset is preloaded |
| The web version measured "half-speed playback" | A picture with many SVG paths cannot keep up in the browser, and testing on the same machine as a 4K render competes for CPU | Test while the CPU is idle (read the progress bar to estimate the rate); reduce detail under `webMode` (drop decorative paths, disable backdrop-filter / full-screen blur) without affecting the finished video |
| The render was stopped midway yet reported success | The output went through a `tee` pipe, so the exit code was tee's | The template's render scripts already use `bash -o pipefail`; add the same to your own piped commands, and verify the duration with `check_video.py` |
| Custom fonts had no effect at all | The title font showed as PingFang/Songti; PingFang looked normal only because macOS falls back to it | `package.json`'s `sideEffects: ["*.css"]` let webpack shake out `import "./lib/fonts"`. The template now includes `./src/lib/fonts.ts`; after changing fonts, capture a frame to confirm the title glyphs really changed |
| `npm install` reports ERESOLVE | `@types/react-dom@^19.2.0` pulled 19.3.0, requiring a higher `@types/react` | The template now pins `@types/react-dom: 19.2.3` with an updated lockfile |
| Chinese web-font project fonts are sliced woff2 | `npm pack @chinese-fonts/xxx` contains no single TTF | Convert all `dist/*/*.woff2` to TTF with fontTools, merge them with `fontTools.merge.Merger`, then put them in `fonts-src/` |
| An AI-generated 1280×720 image looks blurry at 4K | Manga line edges go soft | 4× upscale with Real-ESRGAN (`realesrgan-ncnn-vulkan`, `realesrgan-x4plus-anime` model), then downscale to the target size |
